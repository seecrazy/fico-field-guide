## 界面与入口

`FAGLL03` 按「科目 + 分类账」查总账行项目，是 S/4HANA 新总账（ACDOCA 单表）的主力清单；ECC 没有这个事务码，对应工具是 `FBL3N`（S/4 里仍可跑，底层已是兼容视图，两码分工见[版本差异总表](/00-about/version-matrix)）。查科目余额用 `FAGLB03`，查单张凭证用 `FB03`，FAGLL03 是中间的行项目清单层。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 总账科目 | 查哪个科目，支持区间（如 GR/IR 段） | 敲错 → 空清单或口径错的数 |
| 公司代码 | 限定账套 | 输错 → 别家公司的余额，越权又误导 |
| 分类账 | S/4 多账簿核心维度：0L 主账、并行账簿各自有数 | 漏选/选错 → 金额「少一截」，两套报表对不上 |
| 会计年度 | 行项目取数年度 | 年度错 → 空清单；跨年要按年度分别跑 |
| 过账日期区间 | 收窄范围，默认全年 | 大科目不收窄 → 全量跑，等待极久 |
| 未清项筛选 | 只看未清、只看已清或全部 | 口径错 → 未清清单与月结底稿对不上 |
| 布局（变体） | 决定清单列集，可保存个人变体 | 用默认布局 → 想看的列没有，反复导出 |
| 自由选择 | 按成本中心、分配号、参考二次过滤 | 不会用 → 导 Excel 手工筛，效率差几倍 |
| 清账状态（输出列） | 已清标志 + 清账日期 | 不看 → 已清未清混算，核销口径错 |
| 凭证号（输出列） | 双击或跳 `FB03` 追源头凭证 | 只看数不追凭证 → 审计对不上据 |

### 关键字段深讲

**分类账**。S/4 一笔过账可同时落多个分类账：0L 记本地准则全额，并行分类账（如 IFRS）靠差异凭证单独调整。多账簿环境漏看这个维度，查出的余额与 `FAGLB03`、旧 FBL3N 就对不齐；先固定 0L 基准再比差异，详见[并行账簿](/03-config-notes/parallel-ledger)。

**布局与变体**。清单列由布局决定，可按角色存变体：费用分析多看成本中心、清账核对多看分配号。月结底稿开始前把变体调好，是最划算的一分钟投资。

**自由选择**。相当于旧 FBL3N 的动态选择：按成本中心、分配号、参考等任意组合过滤。GR/IR 月末核对按分配号过滤，直接出「已收货未开票」的对账口径，衔接[GR/IR 清账失败](/01-daily-ops/errors/gr-ir-not-cleared)的排查路径。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 金额与余额表/旧 FBL3N 对不上 | 分类账维度：0L 还是并行账簿 | [并行账簿](/03-config-notes/parallel-ledger) |
| ECC 机器上没有此码 | 用 `FBL3N`；S/4 才有 `FAGLL03` | [版本差异总表](/00-about/version-matrix) |
| GR/IR 未清清单月结对不上 | `MB5S` 分清没到票还是没配对 | [GR/IR 清账失败](/01-daily-ops/errors/gr-ir-not-cleared) |
| 双击行项目报无权限 | `SU53` 看缺哪个权限对象 | [权限失败](/01-daily-ops/errors/authorization-failed) |

## 验证

1. 进 `FAGLL03`：科目 `400000`、公司代码 1000、分类账 0L、当前会计年度，执行。
2. 预期：列出行项目清单，底部带合计。
3. 双击任一行：预期跳到该行 FI 凭证（`FB03` 视图）。
4. 与 `FAGLB03` 同科目比对：预期本年借贷发生额合计一致。
