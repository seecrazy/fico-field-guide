# OB52 — 开闭账期间维护（逐字段详解）

## 界面与入口

`OB52` 按变体维护 FI 可过账期间，是月结开账、期末封账的总开关。与 `MMPV` 的关系要记住：FI 期间与 MM 物料期间相互独立、各自推进，`OB52` 开了不代表 `MIGO`/`MIRO` 能过账，见 [过账期间未开](/01-daily-ops/errors/posting-period-not-open)。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 变体 | 期间控制按变体维护，公司代码挂在变体下 | 改了没分配到公司的变体，怎么改都不生效 |
| 公司代码（+ 空值=全部） | 限定该行区间适用于哪个公司 | 公司留空改的是全变体默认行，影响面比预想大 |
| 账户类型区间 | 每行一个类型：+ 全部/A 资产/D 客户/K 供应商/M 物料/S 总账 | 类型选错，该开的用户照样报期间错 |
| 从期间/年度 | 开账起点 | 起点写晚，早期间凭证全部被拒 |
| 至期间/年度 | 开账终点（封账线） | 终点写晚旧期间关不住，月结后还能补记账 |
| 科目区间（限总账行） | 仅 S 类型可限定科目范围单独开闭 | 想给调整科目单独开口却没填区间，规则落不到该科目 |
| 授权组（许可账套） | 该行区间的过账授权控制 | 误填授权组后普通用户被拒，以为期间没开 |

### 关键字段深讲

- **账户类型一行一类**：+ 为兜底行（未单列的类型全按它）；A 资产——`AFAB` 折旧与资产业务；D 客户——销售开票与收款；K 供应商——`MIRO` 与付款；M 物料——`MIGO` 等物料移动的 FI 过账；S 总账——`FB50` 类手工凭证，且可按科目区间单独开口。典型月结：对 K/D/S 开当期+上一期，其他类型只开当期。
- **变体挂接**：公司代码必须分配到该变体（后台「将变体分配给公司代码」），改错变体是最常见的「改了没用」。验证：新进 `OB52` 输对变体能看到该行区间。
- **授权组**：行上维护授权组后，过账还需用户具备对应授权（经典对象如 `F_BKPF_BER`，以你的系统为准）；常用于「期间只对月结负责人开」的封账。权限错与期间错表现相近，先看消息号。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 报「过账期间未开」 | 公司代码挂在哪个变体、对应类型行区间 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| MIGO/MIRO 报期间错 | `MMPV` 物料期间是否同步推进 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 改了期间不生效 | 变体没分配到公司代码/改错变体 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 封账后仍有人过账 | 至期间是否真关、授权组是否漏配 | `SU53`/消息号定位权限与期间 |

## 验证

对公司代码 1000 所在变体的 S 类型行开当期后，`FB50` 在公司 1000 试过账当期凭证应能进模拟；把至期间改回上期再试应被拒并报期间消息（试完恢复原区间）。
