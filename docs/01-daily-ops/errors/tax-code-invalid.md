# 税码无效或不存在 — 过账被税配置拦下

> 一句话：先分清「税码在这个国家没维护」还是「科目没挂税码」——前者去 `FTXP`，后者去 `OBBG`，别上来就改凭证。

## 消息文本

现象：`FB60` 选税码后模拟或保存报「税码无效/不存在」类提示。消息号以你的系统为准。

## 什么时候出现

- 新公司代码或新国家上线，税码没带全。
- 凭证抬头国家与税码所属国家不一致。
- 税码被冻结/删除后历史流程还在引用。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 税码未在该公司代码所属国家维护 | `FTXP` 按国家+税码查询 | 在对应国家维护税码及税率，走传输 |
| 2. 科目没挂税码：税科目分配缺规则 | `OBBG` 查规则→科目的分配 | 补规则并挂税科目 |
| 3. 凭证用的国家与税码国家不一致 | 回凭证看抬头国家与税码 | 改国家或换该国家维护过的税码 |
| 4. 税码被冻结或带删除标记 | `FTXP` 看冻结/删除标记 | 解冻或换有效税码，删除走变更管理 |

## 怎么验证

**验证 T-Code**：`FTXP`
**验证判据**：按国家+税码能查到且无冻结/删除标记；`FB60` 模拟过账税额计算正确
**失败对照**：税码查得到仍报错 → 回 `OBBG` 查科目分配，多为第 2 类根因
