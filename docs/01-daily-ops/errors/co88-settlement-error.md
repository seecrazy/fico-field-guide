# CO88 批量结算报错 — 订单结算卡住月结

> 一句话：从结算日志把报错订单按类型分堆批量修，修完重跑 `CO88`——可重复执行，已结订单自动跳过；先 WIP（`KKAO`）后结算，顺序不能反。

## 消息文本

现象：月结 `CO88` 大量订单报错或运行中断，日志成页报差异无法分配、结算规则无效、对象被锁。消息号以你的系统为准。

## 什么时候出现

- 月结批量结算生产订单，错误刷屏，科目结平跟着停。
- 上期订单没结完，本期终算被拦下。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 订单未 TECO 就参与终算，差异/WIP 计算前提不满足 | `KOB1` 查订单系统状态 | 补 TECO（`CO02`/`KO02`），未完工走 WIP 流程 |
| 2. WIP 未先计算（`KKAO` 没跑，月结顺序错） | 核对月结清单 WIP 步骤 | 先跑 `KKAO` 再跑 `CO88` |
| 3. 结算规则缺失或结算对象无效（成本中心被锁、PA 特征缺失） | 查报错订单结算规则与接收方 | 补/修结算规则，解锁接收对象 |
| 4. 期间或成本要素被锁 | `OB52` 查期间与要素状态 | 放行所需期间/要素，结算完恢复锁定 |
| 5. 上期订单未结转 | `KOB1` 查上期未结订单 | 补结上期再跑本期 |

## 怎么验证

**验证 T-Code**：`CO88`
**验证判据**：重跑日志无错；`KOB1` 抽查报错订单余额已结平；当期生产成本科目无残留未结算差异
**失败对照**：仍有报错 → 回日志定位新一批错误订单，多集中在第 3 类
