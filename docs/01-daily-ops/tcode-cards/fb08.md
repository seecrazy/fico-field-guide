## 界面与入口

`FB08` 把已过账凭证反向冲掉：生成借贷相反的冲销凭证，原凭证头部标「已冲销」。最稳的进法是从 `FB03` 打开原凭证、经环境菜单进入，三要素自动带出。它只冲 FI 凭证：MIRO 发票类错账从源头模块冲，FI 侧自动联动。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 凭证号 | 定位要冲的原凭证 | 输错 → 冲掉别人的凭证，事故级错误 |
| 会计年度 | 原凭证过账年度，与凭证号配对 | 错年度 → 定位到同号另一张或查无 |
| 公司代码 | 原凭证归属账套 | 错公司 → 冲销凭证落错账套，两边余额都错 |
| 冲销原因 | 冲销口径：惯例 01 冲后可重录、02 禁止重录 | 该用 01 用了 02 → 原分录重录被拦 |
| 冲销过账日期 | 冲销凭证落哪个期间 | 落已关期间 → 报过账期间未开 |
| 冲销凭证日期 | 冲销凭证业务日，默认同过账日期 | 随意改 → 账龄与披露口径乱 |
| 过账期间（显示） | 随冲销日期带出，提示落点 | 不看它 → 报错才知道期间错 |
| 账簿组（S/4） | 冲销凭证过到哪个/哪些分类账 | 多账簿漏选 → 只冲 0L，并行账簿还挂着原账 |
| 摘要（可选） | 冲销原因的人读说明 | 空 → 半年后没人说得清为何冲 |

### 关键字段深讲

**冲销原因 01 / 02**。惯例口径：01 = 冲后允许重新过账原分录（录错重录）；02 = 不允许再过（业务作废、正式更正，防反复过账）。原因代码还带「是否允许替代过账日期」等属性，属性在后台配置定义，以你的系统为准。手误用 01，业务否决用 02。

**冲销过账日期**。冲销凭证默认落当前期间；要回原期间（上月错账本月发现），需同时满足：原因代码允许替代过账日期、原期间在 `OB52` 仍开放、原期间未关账。落不回去的通行口径是落当期并披露。被拦的排查见[冲销失败](/01-daily-ops/errors/reversal-not-possible)。

**冲销前置：清账状态**。原凭证的行被收付款或手工清账挂住时，FB08 直接拒绝；先 `FBRA` 重置清账再冲销。判断入口：FB03 看行项目已清标志。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 报无法冲销/科目已清账 | 行项目已清标志，先 `FBRA` 重置 | [冲销失败](/01-daily-ops/errors/reversal-not-possible) |
| 冲销日期进不了目标期间 | `OB52` 区间 + 原因代码是否允许替代日期 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 冲销凭证号不连被审计问 | `FBN1` 号码段缓冲逻辑 | [凭证号跳号](/01-daily-ops/errors/doc-number-gap) |
| 多账簿只冲了主账 | 账簿组字段选了什么 | [并行账簿](/03-config-notes/parallel-ledger) |

## 验证

1. `FB03` 打开一张本月自录凭证（`FB50` 录的最干净）。
2. 环境菜单进 `FB08`，冲销原因 01、冲销过账日期填今天，执行。
3. 预期：完成画面给出冲销凭证号。
4. `FB03` 重开原凭证：头部显示「已冲销」并带冲销凭证号；冲销凭证借贷与原凭证方向相反、金额相等。
