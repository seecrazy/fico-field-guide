# 高频 T-Code 速查卡片

> 一张卡片一个事务码：用途、必填关键字段、最常见错误、30 秒验证——看一眼就能上手。

本页收录 FICO 日常运维最高频的 23 个事务码，按模块分成 6 组。每张卡片四行看完：知道它干什么、要填什么、哪里最容易踩坑、怎么在 30 秒内确认自己用对了。S/4HANA 用户先看 [ECC 与 S/4 差异总表](/00-about/version-matrix)，涉及版本差异的点（如 `FAGLL03` 替代 `FBL3N`）卡片内已单独标注。示例公司代码统一为 1000。

## 总账（FI-GL）

### `FB50` — 总账凭证录入
- **用途**：手工录入总账凭证——费用计提、期末调整等不涉及客户/供应商的分录。
- **必填关键字段**：公司代码 / 凭证日期 / 过账日期 / 科目 / 金额 / 成本中心（损益科目）
- **最常见错误**：过账日期落在 `OB52` 已关的期间，保存即报「过账期间未开」；损益科目漏输成本中心被校验拦下。
- **验证**：过账前点「模拟」，确认借贷平衡、行项目无误再保存；保存后 `FB03` 回查凭证。

### `FB03` — 凭证显示
- **用途**：只读显示任意来源的 FI 凭证（手工、MM、折旧、清账），查凭证头与行项目。
- **必填关键字段**：凭证号 / 公司代码 / 会计年度
- **最常见错误**：只输凭证号查不到——年度或公司代码不对；凭证是否被冲销看凭证头的「已冲销」标识，别凭金额猜。
- **验证**：输凭证号 + 1000 + 正确年度能打开；冲销过的凭证在凭证头能看到冲销凭证号。

### `FB08` — 凭证冲销
- **用途**：冲销已过账凭证：生成冲销凭证，原凭证标记「已冲销」。
- **必填关键字段**：凭证号 / 公司代码 / 会计年度 / 冲销原因代码 / 冲销过账日期
- **最常见错误**：原因代码 01 与 02 不分——01 冲销后允许重新过账原分录，02 不允许（正式更正场景）；冲销过账日期落在已关期间会报错。
- **验证**：冲销完成画面给出冲销凭证号；`FB03` 回看原凭证头已标记「已冲销」。

### `FS00` — 科目主数据集中维护
- **用途**：集中维护总账科目主数据：一次操作同时建/改科目表层与公司代码层数据。
- **必填关键字段**：科目 / 科目表或公司代码 / 科目组 / 未清项管理 / 字段状态组
- **最常见错误**：只建了科目表层、公司代码段缺失，该公司用户 `FB50` 选不到该科目；控制字段挂在哪一层要先分清。
- **验证**：`FS00` 输科目 + 1000 能进入，公司代码数据段完整存在。

### `FAGLL03` — 总账科目行项目显示
- **用途**：按科目查总账行项目与余额；S/4HANA 新总账主力，替代 ECC 的 `FBL3N`。
- **必填关键字段**：科目 / 公司代码 / 分类账（S/4）/ 会计年度或期间
- **最常见错误**：多分类账环境漏选分类账（如 0L 主分类账），查出的金额「少一截」；ECC 系统没有此码，用 `FBL3N`。
- **验证**：科目 + 1000 + 分类账 0L 运行，双击行项目能进凭证，余额合计与 `FAGLB03` 一致。

## 应收应付（FI-AP/AR）

### `FBL1N` — 供应商行项目
- **用途**：按供应商查未清/已清行项目：发票、付款、预付与清账状态一屏跟。
- **必填关键字段**：公司代码 / 供应商 / 未清项与已清项筛选
- **最常见错误**：勾选口径没看清——未清、已清、统计项目是三个独立勾选项；预付、汇票等特别总账项目要单独勾才显示。
- **验证**：双击任意行项目能钻取到 `FB03`；未清/已清金额与筛选口径能对上。

### `FBL3N` — 总账行项目显示（ECC 主力）
- **用途**：按总账科目查行项目清单（ECC 主力；S/4HANA 改用 `FAGLL03`）。
- **必填关键字段**：科目 / 公司代码 / 未清项筛选
- **最常见错误**：科目没激活「行项目显示」（`FS00` 控制数据），只能看余额、出不了行清单。
- **验证**：`FS00` 查该科目「行项目显示」已勾选；`FBL3N` 运行能列出行项目。

### `FBL5N` — 客户行项目
- **用途**：按客户查未清/已清行项目：发票、收款、预收与催款口径。
- **必填关键字段**：公司代码 / 客户 / 未清项与已清项筛选
- **最常见错误**：漏勾「特别总账事务」，以为预收（down payment）没入账；账龄检查要用「未清项」口径而非全部行项目。
- **验证**：分别勾「普通项目」与「特别总账事务」运行，两部分合计等于客户总余额。

### `F-47` — 预付请求登记
- **用途**：登记供应商下行付款请求（down payment request）：统计性登记，不动真实负债。
- **必填关键字段**：供应商 / 公司代码 / 金额 / 特别总账标识 F / 凭证日期与过账日期
- **最常见错误**：以为登记完钱就付了——`F-47` 只是请求，必须经 `F-48` 手工过账或进支付运行才真正动账。
- **验证**：`FBL1N` 勾选「统计项目」能查到该请求；真实会计凭证在 `F-48` 过账后才生成。

### `F-48` — 预付款过账
- **用途**：对供应商过账预付款：挂特别总账科目，不与发票直接清账。
- **必填关键字段**：供应商 / 公司代码 / 金额 / 特别总账标识 F / 凭证日期与过账日期
- **最常见错误**：误做成普通借项凭证，预付进了普通应付，后续 `F-44` 清不了账；必须带标识 F 才走预付科目（标识 A 是汇票，别混用）。
- **验证**：`FBL1N` 勾「特别总账事务 F」看到这笔未清预付，对方科目是预付科目而非应付。

## 清账与月结

### `F-44` — 供应商清账
- **用途**：手工清供应商未清项：发票对贷项、部分支付或转剩余项目。
- **必填关键字段**：供应商 / 公司代码 / 凭证日期 / 待清未清项选择 / 部分支付或剩余项目
- **最常见错误**：想全额清却选了「部分支付」，留下一笔剩余未清；跨币种或普通/特别总账的项不能混在一笔里清。
- **验证**：保存后 `FBL1N` 未清清单里该项消失（已清）；清错了用 `FBRA` 重置已清项。

### `F-32` — 客户清账
- **用途**：手工清客户未清项：收款对发票、贷项对借项。
- **必填关键字段**：客户 / 公司代码 / 凭证日期 / 待清未清项选择 / 部分支付或剩余项目
- **最常见错误**：预收（特别总账）与普通发票不在同一标识下，清账界面选不到对方项，需先分别处理或先转换。
- **验证**：保存后 `FBL5N` 双方显示已清，未清合计减少数与本次清账金额一致；误清用 `FBRA` 重置。

### `F.13` — 自动清账
- **用途**：按清账准则批量自动清未清项，月结清理 GR/IR、银行与税务科目的主力。
- **必填关键字段**：公司代码 / 凭证日期 / 清账准则（如按凭证号、采购订单号匹配）
- **最常见错误**：不先跑测试运行直接正式执行，准则不匹配导致误清或漏清；金额不等、跨币别的项清不掉属正常。
- **验证**：先勾「测试运行」核对清单，正式执行后再跑一次测试运行，可清项清单应为空。

### `F.19` — GR/IR 重分类清单
- **用途**：按「已收货未开票 / 已开票未收货」列示 GR/IR 未清项，是月末重分类调整的取数清单。
- **必填关键字段**：公司代码 / GR/IR 科目（或科目范围）/ 会计年度
- **最常见错误**：把它当自动清账跑——`F.19` 只出清单、不清账不过账；科目需激活未清项管理，清单才有内容。
- **验证**：清单分类金额合计与 `FBL3N` / `FAGLL03` 中 GR/IR 未清余额对得上。

### `OB52` — 开闭账期间
- **用途**：按变体、公司代码、科目类型（+、A、D、K、S）维护 FI 可过账期间。
- **必填关键字段**：变体 / 公司代码 / 科目类型区间 / 可过账起止期间
- **最常见错误**：改了期间但变体没分配到公司代码（或改错变体）；FI 期间与 MM 期间（`MMPV`）不同步，收货、发票校验报期间错。
- **验证**：重新进入 `OB52` 查看该行区间正确；用 `FB50` 在目标期间试过账验证开关生效。

## MM 集成

### `MIGO` — 收发货过账
- **用途**：货物移动过账：采购收货、发货、转储与盘点调整，同时生成物料凭证与会计凭证。
- **必填关键字段**：动作（收货）/ 参照（采购订单）/ PO 号与行项目 / 工厂 / 移动类型（默认带出）/ 数量
- **最常见错误**：超出 PO 数量收货被容差拦下；FI 侧科目由 OBYC 决定，事务没配科目时报「无法确定科目」。
- **验证**：过账后凭证页签同时给出物料凭证号与会计凭证号；`MB51` 能按物料凭证回查。

### `MIRO` — 发票校验
- **用途**：对采购订单做发票校验：按 PO 的收货/下单量价自动匹配，过账 GR/IR 与税。
- **必填关键字段**：发票日期 / 过账日期 / 金额 / 税码 / PO 号 / 借贷平衡
- **最常见错误**：数量或价格差异超容差被阻塞（红/黄灯）；税码漏选导致税额不自动计算；过账期间未开直接报错。
- **验证**：过账前看余额区借贷差为 0；过账后 `MB5S` 中该 PO 的 GR/IR 差异收敛。

### `MB51` — 物料凭证清单
- **用途**：按物料、工厂、移动类型、期间查物料凭证清单，追溯 MM 动作与联动 FI 凭证。
- **必填关键字段**：工厂 / 物料或移动类型 / 日期范围
- **最常见错误**：不收窄物料与期间全量跑，大数据量等待极久；查「谁动了库存」先按移动类型和日期缩小范围。
- **验证**：双击清单行能看到物料凭证明细及联动的会计凭证号。

### `MMPV` — 关闭 MM 期间
- **用途**：推进公司代码的 MM 期间：关当前期、开下一期，是月结第一步。
- **必填关键字段**：公司代码 / 允许的期间号
- **最常见错误**：想跳期关月——MM 期间只能一期一期顺序推进；与 `OB52` 的 FI 期间不同步时，MIGO / MIRO 报期间错。
- **验证**：对已关旧期间跑一笔 `MIGO` 测试收货应被拒，下一期可正常过账。

## 资产会计（FI-AA）

### `AS01` — 创建资产主数据
- **用途**：创建资产主数据；资产类别决定屏幕布局、科目分配与编号范围。
- **必填关键字段**：资产类别 / 公司代码 / 资产描述 / 折旧码 / 使用年限 / 成本中心（折旧归属）
- **最常见错误**：折旧码或使用年限沿用默认值没改，`AFAB` 跑出折旧为 0 或异常；成本中心漏挂导致折旧过账到 CO 失败。
- **验证**：保存后 `AS03` 回查，折旧范围的折旧码与使用年限正确。

### `AFAB` — 折旧过账
- **用途**：把当期计划折旧从资产会计过账到 FI/CO，每月一次正式运行。
- **必填关键字段**：公司代码 / 期间 / 运行模式（计划内折旧）
- **最常见错误**：不做测试运行直接正式；期间必须顺序执行，跳期报错；正式跑错只能用冲销模式整期冲回重跑。
- **验证**：测试运行清单无错再正式；重进 `AFAB` 该期间已标记过账、无待过账折旧余额。

## 成本中心（CO）

### `KSB1` — 成本中心行项目
- **用途**：查成本中心实际行项目，FI 过账、分摊结果与统计过账都可追溯。
- **必填关键字段**：公司代码或成本控制范围 / 成本中心（组）/ 期间 / 版本（默认 0）
- **最常见错误**：版本或期间口径选错；统计性过账不改变成本中心余额，别误当成漏记账。
- **验证**：输成本中心 + 当期运行，双击行项目能钻取到源 FI 凭证。

### `KSU5` — 实际分摊执行
- **用途**：按分摊循环把发送方成本中心的初级成本以实际分摊转给接收方，生成分摊凭证。
- **必填关键字段**：成本控制范围 / 分摊循环 / 期间 / 版本
- **最常见错误**：不做测试运行直接正式；接收方规则百分比合计不足 100%，分摊后发送方余额清不掉。
- **验证**：先 `KSV5` 测试运行清单无错，`KSU5` 正式后 `KSB1` 查发送方成本中心余额为 0。
