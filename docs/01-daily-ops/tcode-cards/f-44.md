# F-44 — 供应商清账（逐字段详解）

## 界面与入口

`F-44` 手工清供应商未清项：发票对贷项、付款对发票。与 `F.13` 分工——批量自动清归 `F.13`，清不掉的差额与争议项归 `F-44`；清错回滚用 `FBRA`，见 [FB08 凭证冲销失败](/01-daily-ops/errors/reversal-not-possible)。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 供应商 | 决定拉谁的未清项进选择清单 | 输错供应商清单里根本没有要清的项 |
| 公司代码 | 决定清账公司 | 填错公司拉不出未清项，或串公司数据 |
| 凭证日期/过账日期 | 过账日期决定清账凭证落哪个期间 | 落已关期间保存报「过账期间未开」；跨期清账影响当月余额 |
| 标准未清项选择（凭证号/会计年度/日期等） | 收窄待选未清项范围 | 太宽清单巨长，太窄选不到对方项 |
| 特别总账标识/账户类型 | 决定进普通还是特别总账清单 | 停在普通清单里找预付项，永远选不到 |
| 处理未清项：部分支付/剩余项目 | 决定差额的去向（见深讲） | 想全额清却选「部分支付」，留尾巴未清 |
| 已清算金额输入 | 逐项录入本次清算额 | 录错金额借贷不平无法保存 |
| 不激活项目 | 暂时挂起某项不参与本次清账 | 误激活/挂错项，清账结果与预期不符 |

### 关键字段深讲

- **部分支付 vs 剩余项目**：部分支付：原发票保持未清、金额减少，付款作为部分核销挂其下；剩余项目：原发票全清，差额转成新未清项凭证（可带新基准日）。错误模式：想一次清完却停在部分支付，`FBL1N` 永远剩尾巴；或误用剩余项目「洗新」账龄。按公司口径选，以你的系统为准。
- **不能混清的三条线**：不同凭证货币、普通与特别总账标识、不同账户类型不能在同一笔里配对。症状：看得见却选不进——先核标识与币种。
- **清错了怎么办**：`FB08` 冲不动已清凭证：先 `FBRA` 重置清账再重清。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 清完仍挂一笔未清 | 是否误选「部分支付」；改「剩余项目」或补清 | `FBRA` 重置后重清 |
| 选不到对方未清项 | 特别总账标识/币种是否一致 | [特别总账标识](/03-config-notes/ap-special-gl) |
| 保存报期间错 | 清账凭证过账日期 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 借贷不平无法保存 | 各项「已清算金额」录入 | [F5 702 — 凭证借贷不平衡](/01-daily-ops/errors/f5-702) |
| 清错了要回滚 | `FBRA` 重置已清项 | [FB08 凭证冲销失败](/01-daily-ops/errors/reversal-not-possible) |

## 验证

对供应商 200001、公司代码 1000 打开 `F-44`，标准选择拉出未清项：把一张发票与等额贷项/付款配对激活，模拟平衡后保存；`FBL1N` 未清清单两项消失，已清项可见清账凭证号。
