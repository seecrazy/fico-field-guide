# MB51 — 物料凭证清单（逐字段详解）

## 界面与入口

`MB51` 清单式列出物料凭证行，回答「谁在什么时候动了这个料」。相近：`MB52` 看当前库存（静态），`MB51` 看移动历史（动态）；它是 MM 侧的 `FB03`——选中行经环境菜单跳转联动会计凭证。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 物料 | 限定查哪个料（可区间） | 物料与移动类型都不填 → 全厂全量跑，超时等待 |
| 工厂 | 限定评估区域口径 | 漏填跨厂混跑，清单口径与账对不上 |
| 移动类型（区间） | 定动作类别：101 收货、261 发料、561 期初等 | 填 101~102 只覆盖收货族，发料查不到，误判没人动过 |
| 过账日期（起止） | 按落账期间筛 | 与「录入日期」口径混淆漏掉补账行；全年区间跑极慢 |
| 物料凭证号 | 精确定位一笔移动 | 号抄错一位查空；按物料+日期反查更稳 |
| 用户名 | 定谁过的账，追责审计第一入口 | 不确定来源时漏用，排查范围收不窄 |
| 库存地点 | 收窄到库位级 | 大仓多库位不填，清单噪声大 |
| 采购订单号 | 反查某 PO 的全部货物移动 | 与 `MB5S` 互补：这里看「货」，`MB5S` 看「货 vs 票」 |
| 选择布局（变式） | 定清单列——会计凭证号列默认不显示 | 不加 FI 凭证号列 → 看不到联动会计凭证，误以为没生成 |

### 关键字段深讲

**移动类型区间**：MB51 的筛选灵魂。101/102 收货冲销、261/262 订单发料、551 报废、561 期初——区间写窄查不到、写宽跑不动。经验：先按物料 + 日期 + 单一移动类型拉窄清单，再看分布扩查。

**用户名 + 日期组合**：定位「谁动了这个料」的黄金组合——先按物料 + 日期拉清单，看用户名列锁定人，再按人扩查。列不在默认布局先改布局。

**布局与 FI 联动**：把「会计凭证号」列加进布局后，选中行经环境菜单直达凭证显示，等于把 MB51 变成「物料凭证 → `FB03`」的桥，也是排查「有货无账」的标准走法。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| MB51 有物料凭证、`FB03` 无会计凭证 | 该移动的 OBYC 科目确定链 | [MIGO 收货但 FI 无凭证](/01-daily-ops/errors/migo-no-fi-doc) |
| 想知道某移动借了哪个科目 | 移动类型 → OBYC 事务映射 | [OBYC 配置笔记](/03-config-notes/mm-fi-obyc) |
| 月结关期报有在途事务 | MB51 按期间 + 用户找未完成移动 | [MMPV 无法关期](/01-daily-ops/errors/mmpv-cannot-close) |
| S/4 物料账结算报错要核对移动 | MB51 查跨期与负库存移动 | [物料分类账结算](/03-config-notes/ml-closing-s4) |
| 生产成本对不上查发料 | 261/262 移动与订单归集 | [生产订单结算](/03-config-notes/co-pc-order-settlement) |

## 验证（30-120 秒可执行）

物料 RM001 + 工厂 1000 + 移动类型 101~102 + 当天日期运行：应列出今天 `MIGO` 的收货行；双击进物料凭证明细，经环境/凭证菜单能看到**联动的会计凭证号**并跳转成功。
