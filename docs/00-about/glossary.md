# 术语表

> 遇到不认识的缩写先查这里：按域分组、一词一句，没接触过 SAP 的人也能看懂。

用法很简单：直接 `Ctrl/Cmd + F` 搜缩写或术语（英文原文、中文都收了），一句话看懂它是什么。两点提醒：每个词条给的是**最常用义项**，不同项目语境可能有出入，以你的系统为准；想查某个事务码本身怎么用，去[高频 T-Code 速查卡片](/01-daily-ops/tcode-cards)，想看一个码出现在哪些页面，去 [T-Code 总索引](/tcode-index)。

## 组织与结构

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| CC（Company Code）| 公司代码 | SAP 里独立记账的最小核算单位，一个公司代码一套完整的账；本手册示例统一用 1000。 |
| Company | 公司 | 法律层面的公司，一个公司下可挂多个公司代码；集团合并报表按它逐层向上。 |
| Controlling Area | 成本控制范围 | CO 模块的核算地盘：一个或多个公司代码的成本算在同一个范围内；内部报表口径是否可比就看它怎么划。 |
| Chart of Accounts（CoA）| 科目表 | 一套总账科目的「目录」，公司代码挂上某张科目表才能用上面的科目，多公司可共用一张。 |
| Business Area | 业务范围 | 跨公司代码的业务分区（如按事业部出报表的老口径）；新实现多改用利润中心/段。 |
| Profit Center | 利润中心 | 回答「哪块业务赚钱哪块亏钱」的内部核算对象，通常按业务线或事业部划分。 |
| Segment | 段 | 出分部报告（segment reporting）用的最小区分维度，S/4 凭证拆分后可自动带出。 |
| Plant | 工厂 | MM 的物流单位：库存放哪、成本算哪；对 FICO 来说它同时是「评估区域」。 |
| Purchasing Organization | 采购组织 | 替工厂/公司代码谈价下单的采购单位，一个采购组织可以服务多个工厂。 |
| Sales Organization | 销售组织 | 负责卖货的组织单位，销售订单、开票流程都从它出发。 |

## 总账（FI-GL）

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| G/L Account | 总账科目 | 记账的「账户字典」：费用、资产、负债各归各的科目；分科目表层与公司代码层两层维护。 |
| Reconciliation Account | 统驭科目 | 总账与客户/供应商/资产明细账之间的「桥」：只能由业务自动记账，不许手工直接过账。 |
| GR/IR | 收货/收票清算科目 | 货到了发票没到（或反过来）先挂在这，两边齐了自动清掉；月结最常盘的就是它。 |
| ACDOCA | 统一日记账表 | S/4 的「万能明细表」：FI、CO、资产等各模块行项目都记在这一张表里，报表直接读它。 |
| BSEG | 凭证行项目表 | ECC 存 FI 凭证行项目的著名大表；S/4 里它还在，但报表角色已交给 ACDOCA。 |
| New G/L | 新总账 | 支持多分类账与凭证拆分的总账架构：ECC 时代可选激活，S/4 里强制，没有「旧总账」了。 |
| Ledger 0L | 分类账（0L）| 平行记账的「账本」；0L 是主分类账，法定口径走它，其他准则/管理口径可另设并行分类账。 |
| Field Status Group | 字段状态组 | 控制录凭证时每个字段是必输、可选还是隐藏；字段填不了/看不见，先查它。 |
| Document Type / Number Range | 凭证类型/号码段 | 凭证的「型号」（SA 总账凭证、RE 发票等），每种类型用一段独立的凭证号，一眼可辨来源。 |
| Posting Period | 过账期间 | 只允许在「开着」的期间记账：FI 的开关在 `OB52`，MM 的在 `MMPV`，两边必须对齐。 |
| Open Item | 未清项（开放项）| 还没结清的发票/账单：发票一开就是未清，等付款对上它才变已清。 |
| Clearing | 清账 | 把未清项和它的对手动作（付款、收款、贷项）勾对销掉，未清清单从此不再出现它。 |
| Special G/L Indicator | 特别总账标识 | 同一客户/供应商把预付款、汇票、保证金挂到别的科目用的标记（如 A、F）；查这类账要专门勾选才看得到。 |
| Document Splitting | 凭证拆分 | 保存凭证时系统自动按利润中心、段等维度把行项目拆细，让每个维度都能独立出平衡的报表。 |

## 应收应付（FI-AP/AR）

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| Payment Terms | 付款条件 | 约定「多久内付款、早付给多少折扣」的规则，如 2/10 net 30 = 10 天内付打 2% 折、30 天付清。 |
| Cash Discount | 现金折扣 | 提前付款换来的折扣（SAP 术语 Skonto），开票、付款、清账全程围绕它算。 |
| Base Date | 基准日 | 付款条件从哪天起算的那一天，通常取发票日期或入账日期——差一天，到期日就差一天。 |
| Payment Run | 付款运行 | `F110` 的批量自动付款：按规则自动挑到期发票、生成付款凭证和付款文件。 |
| Aging | 账龄分析 | 把未清项按拖了多久（30/60/90 天…）分桶列示，看谁欠得久、该催谁。 |
| Credit Management | 信用管理 | 给客户设授信额度、超限就拦单的控制机制；新旧两套实现并存（见 FSCM）。 |
| FSCM | 财务供应链管理 | SAP 的财务供应链组件，也是信贷管理的新家：S/4 主推 FSCM 信贷，经典 FI 信贷被替代。 |

## 资产会计（FI-AA）

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| Asset Class | 资产类别 | 资产的分类模板：决定编号范围、屏幕布局、默认折旧规则和记账科目（如房屋、机器、车辆）。 |
| Depreciation Area | 折旧范围 | 一套折旧口径：同一资产按账面、税法、集团准则各算一套折旧，互不干扰。 |
| Technical Clearing Account | 技术清账科目 | S/4 新资产会计的过渡科目：资产购置分两段过账、由它自动清平，期末余额应为 0。 |
| APC | 购置与生产成本 | 资产的入账原值（Acquisition and Production Cost）：买价、税费、安装费等资本化投入的合计。 |
| AFAB / AJAB | 折旧过账/资产年度封账 | `AFAB` 每月把折旧过到 FI；`AJAB` 在年末把资产会计的年度锁死，锁后该年度不许再过账。 |
| AuC | 在建工程 | Asset under Construction：没完工转固的成本先归集在它上面，完工后结算到正式资产。 |

## 成本控制（CO）

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| Cost Center | 成本中心 | 成本发生的「责任田」：哪个部门花的钱，就记到哪个成本中心头上。 |
| Internal Order | 内部订单 | 临时归集成本的对象：一次展会、一个维修项目，结束后结算出去关闭。 |
| Primary Cost Element | 初级成本要素（类别 41）| 从 FI 真金白银流进 CO 的成本科目（费用类），类别编号 41。 |
| Secondary Cost Element | 次级成本要素（类别 42）| CO 内部结转用的「内部科目」（类别 42）：分摊、作业分配时才出场，不对外。 |
| Assessment | 分摊 | 用次级成本要素把成本搬到别的成本对象：搬完后对方只看到一笔汇总，看不到原始明细。 |
| Distribution | 分配 | 原样搬运初级成本：对方行项目仍带原始成本要素，明细可追溯。 |
| Statistical Key Figure | 统计关键指标 | 按人头、面积、工时等非金额指标分摊成本的「秤」，只统计、不改账。 |
| CO-PA | 获利能力分析 | 按客户、产品、地区等维度看利润的分析模块；账目基与总账集成、成本基仅 CO，S/4 只保留账目基。 |
| Material Ledger | 物料账 | 物料的实际成本账本：S/4 强制激活，月末要跑物料账结算（`CKMLCP`）。 |
| Actual Costing | 实际成本 | 用物料账在月末把标准价与实际的差异摊回去，重估出真实成本。 |
| Standard Cost | 标准成本 | 预先定的标准价：平时按它记账，差异单独挂出来，月末分析。 |

## MM 集成（MM-FI）

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| Valuation Class | 评估类 | 物料主数据上的记账分类：原材料、成品各挂一个，OBYC 靠它决定记到哪个科目。 |
| Movement Type | 移动类型 | 库存动作的编号：101 收货、201 发料——动什么库存、记什么账都由它定。 |
| Invoice Verification | 发票校验 | 对着采购订单和收货核对供应商发票（`MIRO`），对得上才入账。 |
| OBYC | MM 自动记账配置 | 收发货、发票校验记哪些科目在这里配；配漏了就是「收货成功但没有会计凭证」。 |
| BSX | 存货事务 | OBYC 里决定存货科目的事务：收货时借记哪个存货科目，看它。 |
| WRX | GR/IR 事务 | OBYC 里管 GR/IR 清算科目的事务：收货贷记、发票借记，两边自动对上。 |
| PRD | 价格差异事务 | OBYC 里管价格差异的事务：标准价下的采购价差、发票价差记到哪个科目。 |
| GBB | 冲抵科目事务 | OBYC 里的「兜底」冲抵事务：发料、盘点、订单结算等动存货时的对冲科目都在它的细分下。 |
| MB5S | 收发发票差异清单 | 列出「收货量 ≠ 发票量」的采购订单，月结催票、GR/IR 分析的第一张清单。 |
| 三单匹配 | PO-收货-发票核对 | 采购订单、收货单、供应商发票三方的数量金额核对一致才允许付款，防多付错付。 |

## 版本与技术

| 缩写/术语 | 中文 | 一句话解释 |
|---|---|---|
| ECC | SAP 上一代 ERP | ERP Central Component：R/3 的后继、S/4 之前的主力版本，常配 EHP 增强包使用。 |
| S/4HANA | SAP 新一代 ERP | 跑在 HANA 内存数据库上的现役版本：ACDOCA 单表、新总账强制、物料账强制都是它的标志。 |
| EHP | 增强包 | Enhancement Package：ECC 的功能增强包，不升级版本也能分批启用新功能——装了不等于开了。 |
| FPS | 功能包栈 | Feature Package Stack：S/4 的发布节奏单位，版本号后面的数字越大功能越全。 |
| Fiori | SAP 新一代界面 | 浏览器/移动端的「App 化」界面：同一笔业务在 Fiori App 里操作，与经典事务码并存。 |
| IDES | SAP 演示系统 | Internet Demonstration and Evaluation System：带全套虚构演示数据的 SAP 教学环境，练手专用。 |
| TR | 传输请求 | Transport Request：把开发和配置从开发系统搬去测试、生产系统的「搬运单」。 |
| Client | 客户端 | 同一套系统里的逻辑隔离租户：100 开发、800 生产之类，客户端之间数据互不可见。 |
| Customizing | 定制化配置 | 不写代码、通过配置项改系统行为的设置（记进 TR 可传输），区别于写代码的开发。 |
| IMG | 实施指南 | Implementation Guide：`SPRO` 进去的配置总目录，SAP 全部 Customizing 的入口。 |
| Simplification List | 简化清单 | S/4 官方发布的功能变化清单：什么被删了、什么被替代了，升级评估必读。 |
| Golden Tax | 金税接口 | 中国本地化的增值税发票对接：把 SAP 开票数据传给税控系统开票，具体形态以你的系统为准。 |
