# templates/ — 可下载工作模板

全部为 UTF-8 with BOM 的 CSV，Excel 双击打开中文无乱码；按项目实际增删行。

| 文件 | 用途 | 配套页面 |
|---|---|---|
| `integration-test-script.csv` | 集成测试脚本（P2P/O2C/月结三脚本工作表结构） | `/02-project/integration-test` |
| `month-end-checklist.csv` | 月结检查清单（带勾选列与责任人列） | `/01-daily-ops/month-end-checklist` |
| `config-spec.csv` | 配置说明书骨架（配置对象/事务码/验证判据，交付文档起点） | `/02-project/blueprint-questions` |
| `uat-test-cases.csv` | UAT 测试用例（期望/实际/缺陷关联，用户验收） | `/02-project/integration-test` |
| `issue-tracker.csv` | 问题跟踪表（现象/复现/严重度/状态/回归，Hypercare 期间直接用） | `/02-project/hypercare` |
