## 界面与入口

`FS00` 是科目主数据集中维护入口：输科目 + 公司代码，一屏同时维护「科目表层」与「公司代码层」。兄弟事务：`FSP0` 只动表层、`FSP2` 只动代码层，`FS01/02/03` 是旧入口。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 科目号 | 主数据的键，按科目组号段取号 | 超出号段 → 建不了；串号 → 跨公司口径冲突 |
| 科目表 / 公司代码（入口） | 输科目表改表层；输公司代码进集中视图 | 只建表层没建代码层 → `FB50` 报 F5 100 |
| 科目组 | 决定取号区间与字段布局 | 选错 → 号段与屏幕都不对，只能重建 |
| 科目名称 | 短文本，报表显示口径 | 随手起名 → 对着报表猜科目 |
| 损益标识（P&L） | 损益还是资产负债，决定年结余额转法 | 建反 → 损益年末不清零，年底炸锅 |
| 统驭科目类型 | D 客户、K 供应商、A 资产，绑到子分类账 | 误设 → 禁止直接过账；该设不设 → 往来账失控 |
| 字段状态组 | 控制过账时各字段必输/可选/隐藏 | 配错 → 字段看不见或强制必输，冲突报错 |
| 科目货币 | 允许过账的币种，空白 = 任意 | 与业务币不符 → 过账被拒 |
| 未清项管理 | 科目按未清/已清逐笔管理 | 该开不开 → F.13 清不了账；滥开 → 记账变重 |
| 行项目显示 | 允许按科目拉行项目清单 | 不勾 → 只看余额，出不来清单 |
| 冻结标记 | 冻结新建或过账的停用开关 | 忘冻旧科目 → 一直有人过账；误冻 → 全员被拦 |

### 关键字段深讲

**表层 vs 公司代码层**。名称、科目组、损益标识挂表层，全公司共享；字段状态组、统驭类型、未清项、冻结挂公司代码层，每家独立。F5 100 九成根因是「表层建了、代码层没建」：`FS00` 输科目 + 1000 弹创建提示即实锤，见[F5 100](/01-daily-ops/errors/f5-100)。

**统驭科目类型**。取值看业务架构：应收 D、应付 K、资产 A。挂了统驭类型的科目禁止 `FB50` 直接过账，只能由子分类账业务带出——总账与往来账对齐的第一道防线。误挂的先清往来才能改。

**未清项管理**。只对需逐笔核销的明细类科目（统驭、GR/IR `191100`、银行清算类）开启；开了它行项目才有已清/未清状态，F.13 清账、F.19 重分类才有作用对象。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| `FB50` 敲科目报 F5 100 | `FS00` 查 1000 层建没建 | [F5 100](/01-daily-ops/errors/f5-100) |
| 录凭证字段看不见/强制必输 | 字段状态组 + `OBC4` 组定义 | [字段状态冲突](/01-daily-ops/errors/field-status-conflict) |
| 改字段状态组后行为反常 | 科目组与过账码的叠加逻辑 | [字段状态组](/03-config-notes/gl-field-status) |
| S/4 里科目维护拿不准 | FS00 仍可用，Fiori 另有应用 | [版本差异总表](/00-about/version-matrix) |

## 验证

1. 进 `FS00`，输 `400000` + 公司代码 1000，回车。
2. 预期：不弹创建提示、直接进维护屏——代码层存在。
3. 开「控制数据」页签：预期字段状态组非空、行项目显示勾选可查。
4. 顺手 `FB50` 敲 `400000` 回车：预期能带出名称，不报 F5 100。
