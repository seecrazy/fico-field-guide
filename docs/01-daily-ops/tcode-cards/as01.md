# AS01 — 创建资产主数据（逐字段详解）

## 界面与入口

`AS01` 建资产主数据；`AS02` 改、`AS03` 查——同一界面三种模式，查用 `AS03`。建完不会立刻有账：等 `F-90` 等资本化过账才有值，`AFAB` 才开始折旧。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 资产类别 | 决定科目确定（OAOA）、屏幕布局、编号范围 | 选错类 → 购置/折旧进错科目，事后靠转移纠正 |
| 公司代码 | 定资产归属账套（1000） | 建错公司 → 跨公司转移比重建麻烦 |
| 参考资产 | 复制既有资产默认值 | 参考对象折旧参数异常，错误被复制 |
| 类似资产数量 | 一屏建多件同规格资产（各自独立编号） | 本想 1 台填成 5 → 5 个资产号都要清理 |
| 描述 | 资产检索第一关键字 | 描述随意 → 盘点审计按名称找不到资产 |
| 数量 + 单位 | 台/套计量，供盘点对照 | 单位乱填（套装当单台）盘点数量对不上 |
| 折旧码（折旧范围页签） | 定折旧方法与期间控制逻辑 | 沿用默认没改 → `AFAB` 折旧为 0 或方法异常 |
| 使用年限 | 与折旧码共同定每期折旧额 | 年限错 → 月折旧与累计折旧全错 |
| 期间控制 | 定月内起折/止折规则（当月或次月起折） | 中途购置资产当月是否起折全靠它 |
| 成本中心（时间依赖页签） | 折旧费用的 CO 归属 | 漏挂或挂错 → 折旧过账到 CO 失败或串中心 |

### 关键字段深讲

**资产类别**：一个字段锁死三件事——科目确定（购置/折旧/报废各走哪组科目）、屏幕布局、编号范围。ECC 与 S/4 机制一致，差异是 S/4 购置先过技术清账科目再向折旧范围清账。选错类的代价在第一笔过账后才暴露。

**折旧码 + 使用年限**：折旧码是方法（直线、余额递减等），年限是节奏，组合决定每期计划折旧，`AFAB` 只是执行者。典型错误：默认值没核对，整个生命周期折旧全错。排查入口：`AW01N` 看各年度计划值。

**成本中心**：折旧费用是损益，必须落到 CO 对象——没有成本中心，`AFAB` 在该资产行报错。取自时间依赖页签、按有效日期分段，组织调整记得同步维护。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| AFAB 折旧为 0 或异常 | 折旧码、年限、期间控制 | [AFAB 折旧过账报错](/01-daily-ops/errors/afab-depreciation-error) |
| 折旧过账报缺成本对象 | 时间依赖页签的成本中心 | [成本中心缺失](/01-daily-ops/errors/cost-center-missing) |
| S/4 购置挂技术清账科目 | 技术清账科目配置 | [S/4 新资产会计差异](/03-config-notes/asset-s4-diff) |
| 购置进错科目 | 资产类别 → 科目确定链 | [S/4 新资产会计差异](/03-config-notes/asset-s4-diff) |

## 验证（30-120 秒可执行）

`AS01`：资产类别选常用类别（以你的系统为准），描述「测试-打印机」，折旧范围维护折旧码与年限 5，成本中心填有效中心。保存得号后 `AS03` 回查三项齐全；`AW01N` 计划折旧大于 0。
