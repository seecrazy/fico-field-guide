## 界面与入口

`FB03` 只读显示任意来源的 FI 凭证：手工（`FB50`）、发票校验（`MIRO`）、收发货（`MIGO`）、折旧（`AFAB`）、清账的都能查。兄弟事务：`FB02` 改文本、`FB09` 改行项目文本，冲销从环境菜单直达 `FB08`；FBL3N/FAGLL03 双击也落这里。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 凭证号 | 定位凭证的键，按号码段取号 | 敲错 → 查无；不同段可能重号，须配齐三要素 |
| 公司代码 | 凭证归属账套 | 输错 → 别家公司同号凭证，或不存在 |
| 会计年度 | 凭证号按年度循环 | 年度错 → 查到另一年同号凭证或查无 |
| 凭证类型（头部） | SA 手工、RE 发票、KZ 付款等来源归口 | 判断错 → 追查方向跑偏 |
| 凭证日期 / 过账日期 | 业务日与入账期间，跨期核对第一眼 | 不看 → 账龄月结口径乱 |
| 已冲销标志（头部） | 标明是否被冲销并给冲销凭证号 | 只看金额猜 → 已冲销凭证仍当有效账 |
| 过账码 | 40 借、50 贷等方向控制 | 看错方向 → 记反的凭证混过月结 |
| 科目 | 本行落到哪个科目 | 不逐行核 → 串户凭证发现不了 |
| 金额 / 货币 | 本行金额与事务货币 | 外币不看币种 → 折算差异说不清 |
| 清账状态 | 已清/未清标志与清账日期 | 误判 → 未清清单与实际不符 |
| 环境-物料凭证 | 跳转联动的 MM 单据 | 不知入口 → 收货发票两头断线 |

### 关键字段深讲

**三要素：凭证号 + 公司代码 + 年度**。缺一查不到是头号坑：凭证号按「号码段 × 年度」循环，跨年同号正常。先对年度——特殊期间（13-16 期）属上一年度；再核公司代码。断号先想号码段缓冲，见[凭证号跳号](/01-daily-ops/errors/doc-number-gap)。

**已冲销标志**。凭证有没有效看头部不看金额：被冲销的凭证头部带标志并给冲销凭证号，双击可跳。原凭证与冲销凭证都留在账上，正是审计痕迹；撤销冲销就再冲冲销凭证。冲不动的见[冲销失败](/01-daily-ops/errors/reversal-not-possible)。

**环境菜单**。头部「环境」是追溯总入口：冲销、物料凭证、付款凭证从这里跳；「有货无账」就从物料凭证环境找 FI 凭证号，见[MIGO 无 FI 凭证](/01-daily-ops/errors/migo-no-fi-doc)。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 输了凭证号却查不到 | 三要素是否齐、年度对不对 | [凭证类型与号码段](/03-config-notes/doc-type-number-range) |
| 审计追问凭证号断号 | `FBN1` 看号段已用与缓冲 | [凭证号跳号](/01-daily-ops/errors/doc-number-gap) |
| 以为错账没处理，其实已冲销 | 头部「已冲销」标志与冲销凭证号 | [冲销失败](/01-daily-ops/errors/reversal-not-possible) |
| 打开凭证报无权限 | `SU53` 权限失败记录 | [权限失败](/01-daily-ops/errors/authorization-failed) |
| 想按科目批量拉行项目 | ECC 用 FBL3N、S/4 用 FAGLL03 | [版本差异总表](/00-about/version-matrix) |

## 验证

拿本月自录凭证（`FB50` 刚存的），`FB03` 输凭证号 + 1000 + 当前年度。预期：打开凭证头，凭证日期、过账日期、录入人可见；双击行项目，科目金额成本中心齐全；未冲销凭证头部「已冲销」处为空。
