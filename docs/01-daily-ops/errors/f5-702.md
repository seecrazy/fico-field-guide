# F5 702 — 凭证借贷不平衡（事务货币余额不为零）

> 一句话：屏幕底部借贷合计不平凭证就存不进去——先怀疑税额和汇率尾差，再怀疑手误。

## 消息文本

原文：`Balance not zero: 1,000.00 USD debited, 990.00 USD credited`（余额不为零：借方 1,000.00 美元，贷方 990.00 美元）。消息号以你的系统为准。

## 什么时候出现

- `FB50` 录多行凭证，最后一行录完点保存。
- `FB60`/`FB70` 发票过账，自动税额算出小额差额。
- 外币凭证本币折算差出几分钱。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 手误：金额敲错、漏录一行、正负号反了 | 看底部借/贷合计与差额 | 改正金额或补行 |
| 2. 税额差额：手工加了税行又勾了自动计算税 | 凭证预览核对税额行是否重复 | 只保留自动税，删手工税行 |
| 3. 汇率折算尾差：外币平了、本币差几分 | 切本币视图核对合计 | 按客户政策把尾差调进汇兑损益科目（微调一行） |
| 4. 多币种凭证：事务货币与本币只有一边平 | 核对事务货币、本币两组合计 | 调整金额或改用政策允许的另一汇率，两边都平 |

## 怎么验证

**验证 T-Code**：`FB50`
**验证判据**：差额栏为 0.00，事务货币与本币两组合计相等，凭证可保存
**失败对照**：仍报 `F5 702` → 预览核对税额行与抬头汇率类型，多为第 2、4 类根因
