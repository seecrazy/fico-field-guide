# F5 100 — 总账科目在公司代码中不存在

> 一句话：科目在科目表层存在不等于能用——先去 `FS00` 确认公司代码 1000 层的数据有没有建过。

## 消息文本

原文：`G/L account 400000 in company code 1000 does not exist`（总账科目 400000 在公司代码 1000 中不存在）。消息号以你的系统为准。

## 什么时候出现

- `FB50`/`FB60`/`FB70` 录凭证，敲入科目号回车即报错。
- 批量导入把测试机科目清单直接拿到生产机过账。
- 新公司代码上线，科目清单只复制了一部分。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 科目只建了科目表层，未扩展到公司代码 1000（最常见） | `FS00` 输科目+公司代码 1000，看是否弹出创建提示 | `FS00` 补建公司代码层数据（可复制自其他公司代码） |
| 2. 科目号敲错（多位、少位、串号） | 只输科目号查科目表层是否存在 | 改成正确科目号 |
| 3. 科目表分配或取号体系不符 | `OBD4`/`OB13` 核对公司代码 1000 用的科目表 | 对齐科目表分配，按正确科目表取号 |
| 4. 科目带冻结/删除标记，状态异常 | `FS00` 看控制数据中的冻结与删除标记 | 解除冻结或改用替代科目 |

## 怎么验证

**验证 T-Code**：`FS00`
**验证判据**：科目+公司代码 1000 能直接进 `FS00`，无创建提示，无冻结/删除标记
**失败对照**：仍报 `F5 100` → 核对科目号是否输全（前导零）、默认公司代码是否被改
