# 问题诊断中心

> 你不需要知道该查哪个配置——**从"你想干什么但失败了"开始**：输入或点选现象，直达根因排序表与完整排查路径。

<DiagnoseHub />

## 怎么用

1. **搜索框**：用你自己的话描述现象（如"收货成功但财务没账"），标题、现象标签、模块全都会匹配。
2. **现象标签**：点选一个或多个缩小范围（可组合，如同时选「月初第一笔被拦」+「期间未开」）。
3. **结果卡片**：`报错速查` = 根因按概率排序的速查表（30 秒路径）；`排查实战` = 完整破案过程（数据层→主数据层→配置层）；每张卡片带可信度分级（[分级定义](/00-about/conventions)）。

## 没有命中怎么办

- 换个说法再试（用"科目 / 期间 / 折旧 / 付款 / 清账 / 冲销"这类关键词）。
- 去 [T-Code 总索引](/tcode-index) 反查相关页面。
- 页面底部「📝 希望增加内容」提一个 Issue——搜索无结果的高频现象会被优先写成新条目，**你的提问直接决定下个月写什么**。
