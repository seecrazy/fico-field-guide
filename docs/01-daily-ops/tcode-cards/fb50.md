## 界面与入口

`FB50` 是总账凭证的单屏录入：首屏定公司代码与凭证日期，回车进行项目区逐行录「科目 + 借/贷 + 金额」。它只做总账对总账的分录；挂客户、供应商或特别总账标识用 `FB01` 或旧式双屏 `F-02`。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 公司代码 | 决定凭证落哪个账套：期间、号段随它 | 选错 → 科目在该公司没建，报 F5 100 |
| 凭证日期 | 业务单据日，账龄与付款条件基准 | 填错 → 账龄失真、到期日偏 |
| 过账日期 | 决定凭证记入哪个会计期间 | 落已关期间 → 保存报「过账期间未开」 |
| 货币 | 凭证的事务货币，默认本位币 | 外币当天无汇率 → 报未维护汇率（OB08） |
| 科目 | 本行记到哪个总账科目 | 敲错或未建 → F5 100；统驭科目 → 被拒，须由子分类账过账 |
| 借/贷 | 方向即过账码 40 借、50 贷 | 选反 → 借贷不平或余额方向错 |
| 金额 | 行金额，全凭证借贷合计须相等 | 漏行敲错 → 保存报 F5 702 |
| 成本中心 | 损益科目的 CO 归属 | 损益科目漏输 → 报要求分配 CO 对象（KI 280） |
| 摘要 | 行文本，审计底稿口径 | 空着 → 月底讲不清业务 |
| 分配号 | F.13 自动清账的匹配键 | 该填不填 → 自动清账配不上 |
| 参考 | 挂外部单据号便于追溯 | 填错 → 回查对不上源单据 |
| 税码 | 应税业务自动算税生成税行 | 漏选 → 税额不算；叠手工税行 → 差一笔税 |

### 关键字段深讲

**过账日期**。决定期间归属，最易翻车：跨月补录沿用上月日期直接撞已关期间，必须落在 `OB52` 开放区间内；补录走特殊期间审批，或落当期披露。排查见[过账期间未开](/01-daily-ops/errors/posting-period-not-open)。

**成本中心**。损益科目（如 400000）必须带有效 CO 对象，漏输报「要求分配 CO 对象」；若输入框根本不出现，是字段状态组把它抑制了——见[成本对象缺失](/01-daily-ops/errors/cost-center-missing)。

**科目**。回车后过三道闸：表层建没建、公司代码层建没建（F5 100 高发点）、是不是统驭科目（挂 D/K/A 的禁止直接过账）。查因见[F5 100](/01-daily-ops/errors/f5-100)。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 保存报借贷不平衡 | 底部借贷合计差、税额是否重复 | [F5 702](/01-daily-ops/errors/f5-702) |
| 报过账期间未开 | `OB52` 对过账日期所在期间 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 科目回车报不存在 | `FS00` 查 1000 层建没建 | [F5 100](/01-daily-ops/errors/f5-100) |
| 损益科目要 CO 对象 | 成本中心漏输，还是字段被隐藏 | [成本对象缺失](/01-daily-ops/errors/cost-center-missing) |
| 外币报无汇率 | `OB08` 货币对 + 汇率类型 + 日期 | [汇率缺失](/01-daily-ops/errors/exchange-rate-missing) |

## 验证

1. 进 `FB50`：公司代码 1000，凭证日期、过账日期均填今天。
2. 第一行：科目 `400000`、借方 1.00、成本中心任选有效中心；第二行：非统驭资产负债科目（示例 `100201`，以你的科目清单为准）贷方 1.00。
3. 点「模拟」：预期借贷合计相等、无红条。
4. 保存：预期状态栏给出凭证号；`FB03` 输该号 + 1000 + 当年可回查。
