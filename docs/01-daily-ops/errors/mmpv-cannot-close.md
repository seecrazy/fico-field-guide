# MMPV 无法关闭 MM 期间 — 存在未结事务

> 一句话：`MMPV` 只能顺序逐月关、不能跳月——关不动时先清在途事务，再看物料账结算，最后查是不是想跳月。

## 消息文本

现象：`MMPV` 报无法关期，提示存在未完成事务/被锁对象/物料账未结算等。消息号以你的系统为准。

## 什么时候出现

- 月初关上月，还有物料凭证在途或对话未结束。
- S/4HANA 启用物料账，`CKMLCP` 结算没跑完就关期。
- 想跨月一次关两期，被直接拒绝。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 物料凭证在途/未完成（处理中的收发货、未保存对话） | `MB51` 按期间拉清单核对未完成项 | 等事务结束或通知用户保存/退出后重跑 |
| 2. 存在被锁对象（如物料主数据被占用） | 按提示定位被锁对象，处理工具以系统为准 | 释放占用后重跑，必要时协调 BASIS |
| 3. 物料账结算未完成（S/4 `CKMLCP` 在途） | 查物料账结算的期间状态 | 先完成本期结算再关期 |
| 4. 试图跳月关闭 | `MMPV` 首屏看当前期间，确认与目标月相邻 | 逐月顺序：先关 N 月再关 N+1 月 |

## 怎么验证

**验证 T-Code**：`MMPV`
**验证判据**：重复执行提示已是下一期间；`MB51` 无滞留在途凭证
**失败对照**：仍报无法关闭 → 按提示分类：锁类回第 2 行，物料账类回第 3 行
