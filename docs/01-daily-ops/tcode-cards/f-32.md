# F-32 — 客户清账（逐字段详解）

## 界面与入口

`F-32` 是 `F-44` 的客户版：手工清客户未清项——收款对发票、贷项对借项。`F-28` 录收款（可当时直接清），未当场清的挂账收款事后在 `F-32` 统一核销；批量自动清归 `F.13`。清错回滚用 `FBRA`，见 [FB08 冲销失败](/01-daily-ops/errors/reversal-not-possible)。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 客户 | 决定拉谁的未清项进选择清单 | 输错客户，清单里没有要核销的项 |
| 公司代码 | 决定清账公司 | 填错公司拉不出未清项或串数据 |
| 凭证日期/过账日期 | 过账日期决定清账凭证落哪个期间 | 落已关期间保存报「过账期间未开」；影响当月余额 |
| 标准未清项选择 | 收窄待选范围（凭证号/日期/参考等） | 太窄选不到对方项，误判「清不了」 |
| 特别总账标识/账户类型 | 决定进普通还是特别总账清单 | 想核销预收却停在普通清单，选不到那笔项 |
| 部分支付/剩余项目 | 决定部分核销后差额去向 | 想全额核销却停在部分支付，账上留尾巴 |
| 已清算金额 | 逐项录入本次核销额 | 录错金额借贷不平无法保存 |
| 不激活项目 | 挂起暂不参与核销的项 | 挂错项导致核销组合与预期不符 |
| 未清项账龄/到期日显示 | 辅助判断先核销哪张票 | 忽略账龄，逾期统计失真 |

### 关键字段深讲

- **特别总账与普通项不混清**：预收（特别总账，如标识 F）与普通发票不同标识，核销界面互不可见。先把预收转账到可核销状态（客户侧常 `F-39`，以你的系统为准）再清——在 `F-32` 里硬找是找不到的。
- **部分核销与账龄**：部分支付保留原发票未清（账龄延续）；剩余项目差额转新未清项、基准日常重算——「逾期 90 天」会被洗成「未到期」，用于催款口径前先确认政策。
- **收款先入账后清账**：`F-28` 只入账不清时，收款作为未清贷项挂着，`F-32` 里与发票配对；动手前 `FBL5N` 核对双方。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 预收与发票核销不上 | 标识/币种是否一致，先转账再核销 | [特别总账标识](/03-config-notes/ap-special-gl) |
| 收款入账后发票仍未清 | `FBL5N` 看收款是否作为未清项挂着 | [付款到期日不对](/01-daily-ops/errors/due-date-wrong) |
| 保存报期间错 | 清账凭证过账日期 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 借贷不平无法保存 | 逐项「已清算金额」 | [F5 702 — 凭证借贷不平衡](/01-daily-ops/errors/f5-702) |
| 清错要回滚 | `FBRA` 重置已清项 | [FB08 凭证冲销失败](/01-daily-ops/errors/reversal-not-possible) |

## 验证

对客户 100001、公司代码 1000 打开 `F-32`，标准选择拉未清项：一张未清发票与等额挂账收款配对激活，模拟平衡后保存；`FBL5N` 里双方转已清，未清合计减少数与核销额一致。
