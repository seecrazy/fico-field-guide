# 成本对象缺失 — FI 过账要求成本中心但未填或无效

> 一句话：损益科目+没有成本对象=必报错。先补有效中心；`OKB9` 默认派生是配置解法，`OBA5` 降警告只作临时绕行。

## 消息文本

原文现象：`Account 400000 requires an assignment to a CO object`（科目 400000 要求分配一个 CO 对象）。常见消息号 `KI 280`，以你的系统为准。

## 什么时候出现

- `FB50` 录费用科目（40）没填成本中心，保存报错。
- `FB60` 发票费用分摊不全，个别行缺成本对象。
- 中心填了但报无效：被冻结、有效期不覆盖、控制范围不对。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 损益科目行项目没填成本中心（最常见） | 看报错行项目的「成本中心」字段 | 补填成本中心 |
| 2. 中心无效：不存在/被冻结/有效期不覆盖 | `KS03` 查状态与有效期 | `KS02` 解冻或延有效期，必要时 `KS01` 新建或换中心 |
| 3. 成本中心归属不全（新启用 CO，缺利润中心等字段） | `KS03` 看基本数据页签的归属字段 | 补维护后重试（以你的系统为准） |
| 4. 科目本应默认派生成本中心但没配 | `OKB9` 查该科目+公司代码 1000 | 按客户政策配默认派生 |

## 怎么验证

**验证 T-Code**：`KS03`
**验证判据**：成本中心在过账日有效、未冻结，该科目凭证过账成功
**失败对照**：仍报缺成本对象 → 看科目是否还要求内部订单/WBS 等其他 CO 对象
