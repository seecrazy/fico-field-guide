# MIRO — 发票校验过账（逐字段详解）

## 界面与入口

`MIRO` 是发票校验统一入口，同框架也承揽贷项凭证；配套：`MR8M` 冲销、`MRBR` 释放冻结、`MB5S` 看 GR/IR 差异。与 `MIGO` 分工：`MIGO` 贷记 GR/IR，`MIRO` 借记 GR/IR、贷记应付。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 发票日期 | 供应商票面日期，是基线日期与账龄的起点 | 填错 → 到期日错，`FBL1N` 账龄失真 |
| 过账日期 | 定 FI 落账期间（受 `OB52` 控制） | 落已关期间保存即拒；月结后补票改下期 |
| 凭证类型 / 公司代码 | 默认 RE / 1000，决定编号范围 | 公司代码默认值带错，PO 参照选不到行 |
| 参照：采购订单 + 行选择 | 按已收货/下单量带出待结数量与价格 | 行漏勾 → 部分 GR/IR 未清，留尾巴 |
| 金额 + 币种 | 发票总额，与带出值比较生成差异 | 币种选错汇率放大金额；多敲一个 0 被容差拦下 |
| 税码 | 触发税额自动计算并定税务科目 | 漏选 → 余额挂差不平；错选 → 税串税种，申报口径错 |
| 余额区（借贷差显示） | 实时显示借方差/贷方差，为 0 才可过账 | 不为 0 保存报不平；硬凑金额会把差异埋进别的行 |
| 付款条件 + 基线日期 | 决定到期日与现金折扣 | 与 PO 条件不一致 → 付款跑批丢折扣 |
| 文本 / 分配 | 凭证检索键，发票号建议填分配 | 不填 → 事后按发票号反查不到凭证 |
| 行级数量勾选 | 逐 PO 行决定结多少 GR/IR 数量 | 想部分结算却全勾 → 一次结平，后续差异无载体 |

### 关键字段深讲

**税码**：决定税额计算与税务科目。漏选时余额区挂差不平，是显性错误；错选时金额能平但税种口径错，过账后只能 `MR8M` 冲销重做。取值：PO 行默认带出、可改，境外票与服务票常需换码。

**PO 参照与差异去向**：发票价与 PO 价（或移动平均价）的差不悬空——移动平均价物料进重估或价格差异（PRD 口径），标准价物料直接进价格差异，收发票差异另有 UPF 方案。`OBYC` 配偏时表现为「过账成功、差异进了杂项科目」。

**余额区**：屏幕下方的借贷平衡指示是安全带——金额、税、差异在同一张凭证内配平。出现红/绿灯提示先读消息文本，别直接改金额。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 差异进了非预期科目 | OBYC 的 PRD/UPF 规则 × 评估类 | [MIRO 差异进错科目](/01-daily-ops/errors/miro-prd-wrong-account) |
| 税额不自动算/税码报错 | 发票行税码与 `FTXP` 配置 | [税码无效](/01-daily-ops/errors/tax-code-invalid) |
| 保存报过账期间未开 | `OB52` 与 `MMPV` 是否同步 | [MMPV 无法关期](/01-daily-ops/errors/mmpv-cannot-close) |
| GR/IR 月末清不平 | `MB5S` 对 PO 收货与开票 | [GR/IR 清账失败](/01-daily-ops/errors/gr-ir-not-cleared) |

## 验证（30-120 秒可执行）

对 1000 一张已收货 PO（RM001 已 101 收货）走 MIRO：选 PO 行，金额 = 收货量 × PO 价，补税码，确认**余额区借贷差为 0**，模拟后过账。`FB03` 应看到借 GR/IR、贷应付与税；`MB5S` 中该 PO 差异收敛为 0。
