## 一句话结论

> FSV（Financial Statement Version，`OB58` 维护）是把科目表「翻译」成报表的层级树：资产负债表侧（资产/负债/权益）+ 损益表侧（按性质或功能），节点挂科目区间，`F.01` 按树汇总输出——一个科目在一个 FSV 里只能出现一次、区间不重叠、漏网科目进「未分配」，三关全过报表才平。

## 症状

- `F.01` 按财务报表版本跑出来不平：资产负债表侧合计 ≠ 负债 + 权益侧合计，差额恰好等于某几个科目的余额。
- 新建科目明明有余额（`FAGLL03` 查得到），报表里却找不到——科目余额「消失」。
- 年度余额结转（S/4 用 `FAGLGVTR`）跑完，损益类科目仍挂着余额，或留存收益没接住本年利润，权益侧凑不平。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 新建科目没落进任何节点区间（漏分配） | `OB58` 打开未分配科目清单核对科目号 | 扩区间或加节点把科目挂回，重跑 `F.01` |
| 节点区间重叠或漏段，科目归错边或重复归集 | `OB58` 逐节点比对区间起止号 | 区间改连续不重叠，一个科目只属一个节点 |
| 留存收益节点归位错，损益结果没接到资产负债表 | `F.01` 损益表侧净利润 vs 资产负债表侧留存收益 | 核对留存收益节点属性与 `OB53` 留存收益科目 |
| 科目建在 FSV 规划号段之外（如区间只到 399999 却建了 4 开头科目） | `FS00` 查科目号，对照 FSV 最大覆盖区间 | 按规划重建科目，或扩 FSV 覆盖段并评估影响 |

## 配错会怎样

- 报表直接不平交给管理层与审计：FSV 是 `F.01` 财务报表输出的唯一取数逻辑，树错则数错，而且每月都错，不是一次性事故。
- 科目余额「消失」：月结勾稽时科目余额清单与资产负债表对不上，要逐科目考古到 FSV 才发现没进树。
- 留存收益错位：本年利润在资产负债表上「飞」了或重复计列，权益凑不平，年结余额结转跟着乱。
- 未分配科目无人盯：今天漏一个、下月漏两个，报表与总账的口径差越滚越大，最后要整段重建树。

## 怎么配置

1. `OB58` 建财务报表版本（每个公司代码可指定默认版本，分配入口的菜单位置以你的系统为准）。骨架顶层两分：**资产负债表侧**（资产分流动/长期，负债分流动/长期，权益）+ **损益表侧**（按性质分收入/成本/费用，或按功能走销售成本法，与蓝图口径一致）。
2. 节点分配科目区间（示意）：100000-199999 挂「货币资金」节点，200000-299999 应收与预付，300000-399999 应付与其他负债——区间连续、不重叠；**一个科目在一个 FSV 里只能出现一次**。
3. 留存收益节点：资产负债表权益下设「留存收益」节点并标记留存收益属性，承接损益表侧的本年利润；留存收益科目本身在科目表层配置（`OB53`），年度余额结转（S/4 的 `FAGLGVTR`）把损益余额滚入该科目，与 FSV 展示呼应。
4. 未分配科目兜底：`OB58` 有未分配科目检查清单（科目表里存在、树里没挂的科目；菜单位置以你的系统为准），上线前与每次月结前清零。
5. 新科目纪律：`FS00` 建科目时对照 FSV 区间规划建号，建完跑一次未分配清单确认入树——号段规划方法论见[凭证类型与号码段](/03-config-notes/doc-type-number-range)。

## 怎么验证

公司代码 1000，期间 2026 年 11 月，`F.01` 输出选「财务报表」并指定该 FSV。

**验证 T-Code**：`F.01`
**验证判据**：资产侧合计 = 负债 + 权益侧合计（留存收益已承接本年利润）；「未分配科目」清单余额为 0；各节点汇总数与 `FAGLL03` 分科目余额勾稽一致（FAGLL03 用法见[详解页](/01-daily-ops/tcode-cards/fagll03)）。
**失败对照**：不平 → 先打开未分配科目清单，把有余额的漏网科目逐个挂回节点后重跑；仍差 → 逐节点查区间重叠或漏段；损益没接住 → 查留存收益节点属性与 `OB53` 科目是否一致。
