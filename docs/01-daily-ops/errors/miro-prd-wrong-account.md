# MIRO 发票校验差异进错科目 — PRD/UPF 配置偏差

> 一句话：差异金额去哪个科目由 `OBYC` 的 PRD/UPF 规则决定；物料账激活后还要再看一层 `CKM3` 的分摊链。

## 消息文本

现象：`MIRO` 发票校验过账成功，但价格/汇率差异落到非预期科目（如进了杂项）。这是科目确定结果错误而非固定报错；科目缺失时才会在 `MIRO` 当场报错，以你的系统为准。

## 什么时候出现

- PO 与发票价格不一致，首次触发价格差异过账。
- 外币发票产生汇率差异，走了 UPF 而非预期科目。
- 物料账激活后，差异在 `CKM3` 多层被重新分摊。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. PRD 价格差异配错科目（规则指向旧/错科目） | `OBYC` 打开 PRD，查估值修改码下规则 | 改到正确科目并传输 |
| 2. UPF 收发票差异未按客户政策的方案维护 | `OBYC` 打开 UPF，逐方案核对规则 | 按客户政策补齐/修正方案规则 |
| 3. 物料账激活，差异走多层科目链（S/4） | `CKM3` 看该物料的差异分摊路径 | 补配物料账科目确定或调整差异类别 |
| 4. 发票被容差冻结，释放路径与预期不符 | `MRBR` 看冻结原因与清单 | 按容差政策释放；容差调整见 `OMR6`（以你的系统为准） |

## 怎么验证

**验证 T-Code**：`MIRO`
**验证判据**：过账后 `FB03` 凭证里价格差异金额落在政策规定科目
**失败对照**：仍不对 → 回 `OBYC` 核对 PRD/UPF 规则与评估类、分组码
