# MIGO 收货正常但 FI 无凭证 — OBYC 自动记账缺失

> 一句话：收货没有 FI 凭证，九成是 `OBYC` 的 BSX/WRX 没配到这个评估类——先查配置，再查物料主数据。

## 消息文本

现象：`MIGO` 收货成功生成物料凭证，`FB03` 却查不到对应会计凭证，库存科目余额不更新。这是「凭证缺失」状态而非固定消息；部分系统在 MIGO 当场报科目确定缺失，以你的系统为准。

## 什么时候出现

- 新物料类型或新评估类的物料首次收货。
- 新公司代码上线漏配自动记账。
- S/4HANA 激活物料账后，差异类科目链没配全。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. `OBYC` 里 BSX/WRX 没配该评估类的规则（最常见） | `OBYC` 双击 BSX/WRX，查估值修改码下规则 | 补配科目规则并传输 |
| 2. 评估分组码不一致：`OMWD` 里公司代码 1000 的分组码与 `OBYC` 维护用的不同 | `OMWD` 查公司代码 1000 的评估分组码 | 两边对齐为同一分组码 |
| 3. 物料主数据评估类为空或错误 | `MM03` 查会计视图的评估类 | 新料补上；有库存物料需先清库存才能改 |
| 4. S/4 物料账激活但差异科目未配 | `MB51` 定位物料凭证，`FB03` 确认无凭证 | 按物料账科目确定补配（见下方笔记） |

## 怎么验证

**验证 T-Code**：`FB03`
**验证判据**：补配后再过一笔收货，`FB03` 能查到借贷分录齐全的会计凭证
**失败对照**：仍无 FI 凭证 → 回 `OBYC` 逐项核对 BSX/WRX/PRD 规则与评估类、分组码
