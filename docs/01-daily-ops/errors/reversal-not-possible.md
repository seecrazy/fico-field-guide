# FB08 凭证冲销失败 — 已清账或跨期间

> 一句话：冲不回去先查两件事——行是否已清账、冲销期间开没开；顺序永远是先 `FBRA` 重置清账，再 `FB08` 冲销。

## 消息文本

现象：`FB08` 输入凭证号后报「无法冲销/科目已清账」，或冲销日期落到未开期间被拦。消息号以你的系统为准。

## 什么时候出现

- 月结后发现错账，凭证已被收付款清账。
- 跨月冲销：要落到已关的期间。
- 同一张凭证被冲销两次。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 凭证行已清账（收付款/手工清账挂住） | `FBL3N` 看已清标志与清账日期 | `FBRA` 先重置清账（会生成冲销清账凭证），再 `FB08` 冲销 |
| 2. 冲销期间未开：落原期间还是当前期间取决于配置 | `OB52` 核对冲销日期所在期间 | 开区间（走审批）或改冲销日期 |
| 3. 凭证已被冲销过 | `FB03` 看凭证头「已冲销」标志与冲销凭证号 | 冲销那张冲销凭证，或重录新凭证 |
| 4. 不能动原凭证的替代方案 | 核对科目是否允许负数过账 | 直接录负数凭证纠错 |

## 怎么验证

**验证 T-Code**：`FB08`
**验证判据**：保存后 `FB03` 看原凭证头「已冲销」标志与冲销凭证号，金额镜像
**失败对照**：仍报无法冲销 → `FBL3N` 查是否还有未重置的清账行，回到第 1 类根因
