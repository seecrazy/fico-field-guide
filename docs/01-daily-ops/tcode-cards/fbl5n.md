# FBL5N — 客户行项目清单（逐字段详解）

## 界面与入口

`FBL5N` 是 `FBL1N` 的客户版：按客户查未清/已清发票、收款、贷项与预收。与 `FD10N` 分工——`FD10N` 看余额，`FBL5N` 看行项目并钻取 `FB03`。催款与信贷检查的取数口径也以此清单的「未清项」为准。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 客户 | 限定查询对象，支持区间/多选 | 留空全量跑等待极久；输错号「无数据」被当漏开票 |
| 公司代码 | 决定读哪个公司的行项目 | 填错公司查空清单；客户无该公司段同样为空 |
| 未清项 | 只列未清发票/收款，账龄、催款、信贷占用取此口径 | 逾期口径误勾「全部」，已清旧账混进逾期区间 |
| 已清项 | 列已清账项，可限清账日期 | 日期范围太窄看不到历史核销记录 |
| 普通项目 | 显示常规发票、收款、贷项凭证 | 不勾清单为空或只剩特别总账项，误判客户余额异常 |
| 特别总账事务 | 显示预收（F）、应收汇票（A）等项目 | 漏勾以为预收「没入账」，产生重复确认风险 |
| 统计项目 | 显示统计性登记（如预收请求） | 漏勾以为登记失败；统计项不动余额，别当漏账 |
| 日期范围（过账/到期日） | 收窄区间，账龄分桶靠到期日 | 到期日范围错，逾期天数与催款分级全错 |
| 币种 | 决定金额显示口径 | 本外币混看时合计差汇率折算额 |

### 关键字段深讲

- **未清项与信贷占用**：信贷暴露按未清项+特别总账未清项合计口径取数（哪些标识计入以你的系统为准），见 [信贷管理](/03-config-notes/ar-credit-management)。错误模式：销售说额度不够，实际是预收也占了暴露，`FBL5N` 全口径跑一遍即见分晓。
- **特别总账事务**：预收挂备选统驭科目，默认不显示。错误模式：收到预收查不到，以为入账失败。
- **到期日口径**：账龄按净付款日分桶，付款条件/基准日错整体偏移，见 [付款到期日不对](/01-daily-ops/errors/due-date-wrong)。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 预收款在清单看不到 | 勾「特别总账事务」重跑 | [信贷管理 — 从简单信贷到 FSCM](/03-config-notes/ar-credit-management) |
| 发票到期日不对、账龄整体偏移 | 行项目付款条件与基准日 | [付款到期日不对](/01-daily-ops/errors/due-date-wrong) |
| 收款后发票仍显示未清 | 是否只入账未清账，去 `F-32` 处理 | [FB08 凭证冲销失败](/01-daily-ops/errors/reversal-not-possible) |
| 客户被信贷冻结 | 未清项合计与信贷暴露口径 | [信贷管理 — 从简单信贷到 FSCM](/03-config-notes/ar-credit-management) |

## 验证

输入客户 100001、公司代码 1000、勾「未清项」并全选三个项目类型运行：双击任一行能进 `FB03`；普通+特别总账合计与 `FD10N` 余额一致。
