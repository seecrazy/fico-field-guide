# 字段状态冲突 — 必输字段被抑制或字段不可见

> 一句话：科目字段状态组与过账码字段状态组是叠加生效的——同一字段一边隐藏一边必输，就变成「看不见还非填不可」。

## 消息文本

现象：过账时成本中心、分配等字段不可见，或保存时报必输项却找不到输入框。消息文本随字段而异，以你的系统为准。

## 什么时候出现

- `FB50` 对换了字段状态组的新科目首次过账。
- 升级或传输改了 `OBC4` 组配置。
- 复制公司代码后组号不一致。

## 根因（按概率）

| 根因（按概率） | 验证动作 | 修复动作 |
|---|---|---|
| 1. 两组对同一字段冲突：一边 Suppressed 一边 Required（隐藏优先，最常见） | `FS00` 查科目字段状态组，`OBC4` 看该字段属性 | 改组配置，避免一边隐藏一边必输 |
| 2. 组配置被误改（升级/传输） | `OBC4` 与测试机或传输日志比对 | 修正后重新传输 |
| 3. 跨公司代码复制后组号不一致 | `FS00` 比对同科目在两个公司代码的组号 | 统一组号或本地调整 |
| 4. 前台录入全局设置/屏幕变式干扰（少见） | `FB00` 核对全局参数，`FB50` 换用户重试 | 还原全局设置或换标准屏幕 |

## 怎么验证

**验证 T-Code**：`FB50`
**验证判据**：过账界面能看到并填写该必输字段，凭证顺利保存
**失败对照**：字段仍不可见 → 用 `OBC4` 核对过账码（40/50）侧，冲突常在另一方
