# F-48 — 预付款过账（逐字段详解）

## 界面与入口

`F-48` 对供应商过账真实预付款：借记预付账款（备选统驭科目）、贷记银行，生成正式会计凭证。与 `F-47` 分工——`F-47` 只统计性登记，`F-48` 才动账；预付对发票的核销走后续转账清账。标识体系见 [特别总账标识](/03-config-notes/ap-special-gl)。

## 字段逐个讲

| 字段 | 作用 | 填错会怎样 |
|---|---|---|
| 供应商 | 决定预付挂在哪个供应商名下 | 输错供应商，清账时在正确供应商下找不到这笔预付 |
| 公司代码 | 决定过账公司 | 填错公司，科目与银行账户跟着串公司 |
| 凭证日期/过账日期 | 凭证日期记业务、过账日期定期间 | 过账日期落已关期间保存报「过账期间未开」 |
| 银行账户选择 | 决定贷方银行科目（`FBZP`） | 选错账户，银行对账时单据挂错账户找不到 |
| 付款方式 | 决定付款路径与银行科目取数 | 付款方式错，取错银行科目或自动付款不认 |
| 币种/金额 | 预付金额 | 多付只能靠退款或下次核销消化 |
| 特别总账标识 | 选 F 才走预付备选统驭科目 | 漏选 F 变普通借项，挂进应付统驭科目，核销路径全错 |
| 基准日期 | 预付未清项的账龄起点 | 填错影响账龄与到期判断 |

### 关键字段深讲

- **特别总账标识 F 与 A 别混**：F=预付款，挂预付备选统驭科目；A=汇票，走票据科目与票据管理。错选 A 会把预付做成票据业务，凭空多一张票。科目映射在 `FBKP` 配置，以你的系统为准，详见 [特别总账标识](/03-config-notes/ap-special-gl)。
- **备选统驭科目**：`F-48` 的预付按标识 F 映射到预付科目而非应付统驭科目——所以 `FBL1N` 要勾「特别总账事务」才看得到。错误模式：不带标识做成普通借项，预付混进普通应付，核销时选不到。
- **关于清账**：`F-48` 不清任何发票，只生成新的未清预付项；预付核销走后续转账清账（如 `F-54`，以你的系统为准），别在 `F-48` 里找发票选。

## 高频错误与排查路径

| 症状 | 先查什么 | 去哪页 |
|---|---|---|
| 预付后 `FBL1N` 看不到 | 勾「特别总账事务」；确认带了标识 F | [特别总账标识](/03-config-notes/ap-special-gl) |
| 预付进错统驭科目 | 是否漏选 F 做成普通借项 | [特别总账标识](/03-config-notes/ap-special-gl) |
| 银行科目/账户不对 | 银行账户选择与付款方式 | [F110 自动付款 — FBZP 配置树](/03-config-notes/ap-auto-payment) |
| 保存报期间错 | 过账日期所在期间 | [过账期间未开](/01-daily-ops/errors/posting-period-not-open) |
| 预付后银行对账找不到单据 | 银行账户选择与付款方式 | [银行对账](/03-config-notes/bank-reconciliation) |

## 验证

对供应商 200001、公司代码 1000、标识 F 过账一笔小额预付：`FB03` 查到凭证，借方是预付科目而非应付统驭科目；`FBL1N` 勾「未清项+特别总账事务」能看到这笔未清预付。
